# 非 Anthropic 模型鉴权提示误导

## 复现

用户级 `deepseek` Profile 配置为 `openai-chat`、`https://api.deepseek.com`，`apiKey` 引用 `${OPENAI_API_KEY}`。Windows 用户环境已保存该变量，但当前 Codex 进程没有继承。基准 CLI 在无该变量的进程中退出，报 `Invalid or missing API key. Set ANTHROPIC_AUTH_TOKEN ...`。

## 问题

流式请求把 401 等鉴权错误统一映射为 Anthropic 专用提示，没有结合当前模型 Profile 的协议。用户由此误以为必须有 Anthropic Key。实际上将已有的 `OPENAI_API_KEY` 传给子进程后，DeepSeek 单题探针与 18 次基准均可运行。

## 预期与修复范围

Anthropic 协议继续显示其专用变量；OpenAI 兼容和 Gemini Profile 的鉴权错误应提示检查当前 Profile 的 `apiKey` 及其引用的环境变量。错误消息不输出凭据值。覆盖错误格式化与实际流式错误路径，并运行相关离线检查。
