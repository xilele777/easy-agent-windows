# 迁移独立仓库与更新项目入口

## 迁移结果

经用户确认，创建公开的独立仓库 `xilele777/easy-agent-windows`，将当前 Windows 工作分支的完整 Git 历史推送为新仓库的 `main`，并保留该工作分支。新仓库不是 fork；旧的 `xilele777/easy-agent` fork 保留作来源记录。本地 `origin` 指向新仓库，旧仓库改名为 `upstream-fork` 远端。

## 本次改动

- `package.json` 的 repository、homepage 和问题反馈地址指向新仓库。
- 中英文 README 的源码克隆和问题反馈地址指向新仓库，明确原作者和 MIT 许可证、当前 Windows 方向，以及 npm 上的 `eagent` 仍来自原项目。原项目 banner 和 npm 安装脚本继续标明其来源。
- `learn/WORKLOG.md` 和目录索引更新迁移进度。

## 验收与后续

核对新仓库 `isFork=false`、默认分支为 `main`，确认新提交可从该分支访问、GitHub 将作者关联到 `xilele777`，并检查远端 CI。个人贡献图可能有刷新延迟；后续改动也需合入新仓库默认分支才符合提交贡献统计条件。当前真实模型基准扩展仍按 `learn/plans/0003` 执行。
