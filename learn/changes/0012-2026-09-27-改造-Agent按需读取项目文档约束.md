# Agent 按需读取项目文档约束

## 本次改动

- 将 `AGENTS.md` 和 `AGENT.md` 中的开工阅读规则改为：先看工作日志开头最多 30 行；只有执行或调整某项计划时才读对应计划。
- 明确根目录规则文件是入口，产品说明、历史改造、评审、归档计划等文档按任务定位，不因位于 `docs/` 或 `learn/` 就每次通读。
- 优先按文件名或 `rg` 找到目标，再读相关段落；已有上下文或压缩摘要可用时不重复读取。跨模块任务确需更多背景时继续补读。
- 工作日志中同一天的新进展写在该日期最上方，保证只读开头时也能看到最新结果；目录索引保留当前入口和分类导航，不再逐项列出全部历史改造记录。

## 原因与边界

过去的“开工先看工作日志和当前计划”没有限定读取范围，文档越多，重复读取占用的上下文越大。现在按任务逐步补读，仍允许复杂任务读取完整必要材料；这条规则约束 Agent 的工作方式，不改变产品对用户文档的加载机制。
