# 扩展 Windows 真实模型基准夹具与逐次记录

按[当前计划](../archive/plans/0003-2026-09-27-规划-扩大Windows真实模型基准与失败分析.md)，将三道小题扩为六题：新增跨文件发票计算、Windows 路径边界、配置错误处理。每题独立预置测试和允许修改的文件，运行前验证测试确实失败。

`scripts/benchmark-windows.ts` 现在每题从相同初始文件重复三次，共 18 次。每次使用新的临时 Git 仓库，记录基准提交、夹具哈希、模型 Profile、CLI 与测试退出状态、改动文件和 Git 差异、墙钟与模型报告耗时、Token 及失败类别。`--check-fixtures` 无需模型调用；`--output` 可将逐次 JSONL 证据保存到指定位置。运行结束清理临时仓库，不保存原始模型回复，对已知凭据做脱敏。

复现命令已更新在[测试说明](../../docs/testing.md)。本次改动仅限基准工具与说明，不更改产品权限策略。
