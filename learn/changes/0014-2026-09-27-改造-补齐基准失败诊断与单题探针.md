# 补齐基准失败诊断与单题探针

首次运行扩展基准时，18 次调用都在模型修改文件前退出。Headless JSON 错误结果中的 `result` 为空字符串，原脚本因此漏记了有用的标准错误输出。

现在错误结果为空时会取 CLI 标准错误并脱敏；另加入 `--task` 和 `--repeats`，便于只运行一题一次来核查环境，完整基准仍默认六题各三次。单题探针显示当前进程缺少 `ANTHROPIC_AUTH_TOKEN`，CLI 报“Invalid or missing API key”，故这批中断是环境配置问题，不能计为模型解题失败。复现方法已补入[测试说明](../../docs/testing.md)。
