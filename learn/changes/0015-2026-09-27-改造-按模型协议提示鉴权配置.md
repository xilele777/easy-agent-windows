# 按模型协议提示鉴权配置

修复[非 Anthropic Profile 鉴权提示误导](../bugs/0001-2026-09-27-缺陷-非Anthropic模型鉴权提示误导.md)。流式请求遇到鉴权错误时解析当前模型 Profile 协议，将协议交给错误格式化层：Anthropic 继续提示 `ANTHROPIC_AUTH_TOKEN`；OpenAI 兼容和 Gemini Profile 提示检查对应 Profile 的 `apiKey` 与所引用的环境变量，不再要求 Anthropic Key，也不输出凭据内容。

增加两种提示的回归断言。`npm run typecheck`、`npm run test:resilience`、`npm run test:providerstream` 和构建均通过。用缺少 `OPENAI_API_KEY` 的 `deepseek` 单题探针核验，CLI 现准确提示 `model profile "deepseek"` 的 `apiKey`，脚本将其归类为环境问题。
