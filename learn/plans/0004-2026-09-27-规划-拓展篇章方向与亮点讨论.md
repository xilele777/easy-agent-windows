# 拓展篇章方向与亮点讨论

> 承接[扩大 Windows 基准结果](../reviews/0005-2026-09-27-评审-扩大Windows真实模型基准结果.md)。当前基础阶段已完成基准与相关缺陷修复；下一阶段先与用户讨论方向和亮点，再确定拓展核心功能的实施范围。

## 目标

形成双方认可的拓展主题、用户价值、差异化亮点和优先顺序，之后再写具体实现计划。此计划是讨论与决策入口，不预先选定或启动某个拓展功能。

## 执行顺序

1. 盘点 Easy Agent 当前已具备的核心能力、Windows 主线已验证的范围及未覆盖的风险，避免把已有能力当作新功能重复规划。
2. 提出少量可比较的核心拓展方向；逐一写清目标用户、典型场景、亮点、可验证的效果、实现成本与关键风险。
3. 与用户讨论并选择方向，确定第一批功能边界、优先级及暂缓项。讨论中如有新约束，先更新候选方案再定稿。
4. 将选定方向拆成可复核的工作单元，写新的实施计划与验收标准；涉及外部服务、权限或跨平台行为时明确测试方式。

## 完成标准

方向与亮点得到用户确认，留下决策记录，并形成下一份可执行的功能计划。在确认前保持拓展功能代码不变。
